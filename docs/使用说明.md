# ClearPane 使用说明

正文中的 `![说明](图片地址)` 支持本地图片和 HTTP/HTTPS 网络图片。普通 `[文字](地址)` 链接保持点击复制，不自动展开。

本地路径相对于 Markdown 文件所在目录解析，可使用 `./images/a.png`、`../a.png`、`D:/图片/a.png` 或 `file:///D:/图片/a.png`。包含空格的路径使用尖括号，例如 `![图片](<./图片/测试 图.png>)`，也支持 URL 编码。支持 PNG、JPEG、GIF、WebP、BMP、SVG、AVIF、ICO，每张不超过 20 MiB，仅支持本地磁盘文件。

图片按阅读区域宽度缩放并保持比例，加载失败时保留说明文字及错误提示。网络图片由浏览器直接加载，不发送来源地址，不经过插件代理，格式由浏览器决定。图片数据不进入会话缓存。点击“刷新”重新加载图片；自动更新仅检查 Markdown 正文变化，不监听图片文件变化。

1. 粘贴本地 Markdown 完整路径，点击“打开”。打开成功后顶部收起，保留 ClearPane 标识、待发送按钮和齿轮；悬停或点击齿轮展开。待发送按钮位于齿轮左侧，收起时也能直接打开评论列表。
   也可点击路径框下方的工作区文章列表。列表包含子文件夹中的 .md/.markdown，按最近修改排序，初始显示 3 份；滚到列表底部或点击“加载更多”，每次再加载 3 份。关键词按文件名及相对路径搜索整个列表，重新展开顶部重新扫描工作区。无工作区或列表失败时仍可粘贴路径，包括工作区之外的本地 Markdown。没有“最近打开”记录。
2. 展开顶部，在工具栏的“设置”选择“跟随系统 / 浅色 / 深色”，并调整字号、行高。“跟随系统”跟随 Antigravity 主题；设置会保存。顶部隐藏、按 Esc 收起或切走 ClearPane 时，排版设置自动关闭，再展开顶部时保持关闭。
3. 在正文选中文字，点附近的“评论”，写意见后点“加入待发送”，或在评论表单内按 Ctrl+Enter。原文保留高亮，右侧铅笔按钮打开对应评论，直接修改即可。可重复加入多条，Agent 此时不会运行。删除、清空或成功发送后，对应高亮和按钮移除。
4. 点右上角“待发送”按钮，评论默认折叠，点击“评论 N”后可查看引用、编辑或删除，按需填写统一指令。数字徽标显示当前会话已加入的评论数量，添加和删除时实时更新，未加入的草稿不计数；0 条时使用低调样式，有评论时显示绿色强调。点“统一发送”，或在待发送表单内按 Ctrl+Enter 后，立即返回文章并显示发送状态，全部评论作为一条消息提交并触发 Agent。发送成功后清空评论和统一指令，数量归零，成功提示显示 4 秒后自动隐藏；失败或结果未确认时保留数量、内容和提示，可重新打开待发送列表处理。

每批限同一文件。要切换文件，先发送或清空待发送列表。文件内容刷新后发生变化时，已加入评论保留引用快照，并标注来源变化，旧高亮和正文按钮移除；尚未加入的失效草稿需要重新选区。内容未变化时保留高亮。旧版评论缺少选区定位时，仍可在待发送列表修改。

普通 Enter 在文本框内换行；Ctrl+Enter 仅在对应界面打开且按钮可用时执行，输入法组词期间不触发。

Esc 或点击评论浮层外部收起并保留草稿，可从顶部“继续草稿”恢复；“取消”清空本条。切换到其他程序、切换辅助面板标签、隐藏重开或切换会话后，分别恢复各会话最后一次成功读取的 Markdown、阅读位置、草稿、待发送列表和统一指令。离开前正在编辑的评论框会自动打开，恢复文字及引用；同一页面保留光标位置，页面重建后光标位于文字末尾。主动收起的草稿保持收起。

面板可见时每 2 秒检查当前文章已保存到磁盘的内容，变化后自动更新并恢复滚动比例；隐藏时暂停，返回先恢复评论编辑状态，无评论交互时立即检查。正文存在选区、评论浮层或待发送弹窗打开、正在发送或发送结果未确认时暂停，操作结束后立即检查。收起的草稿不阻止更新，变化后保留评论文字并要求重新选区；已加入评论保留原引用并标记来源变化。文件删除、无权限或编码错误时保留旧预览并自动重试。手动“刷新”入口继续可用。

正文与评论仅缓存在 sidecar 进程内，不写回 Markdown，也不写入磁盘。退出客户端或重启插件后清除；排版和主题设置继续保存。面板不可见时不能发送。页面重建遇到发送中状态时，显示结果未确认，需先检查主会话再解锁重试。

引用最多 8,000 字符、每条评论及统一指令各最多 4,000 字符、整批消息最多 14,000 字符。超限需缩小本批内容。发送结果不明时，先检查主会话，确认尚未收到后再解锁重试，避免重复发送。

## 构建与更新

运行 `npm run package`，离线插件目录为 `dist/antigravity-clearpane`。本机更新前在 Antigravity 的 Installed 停用插件，执行 `npm run install:local -- --update`，再启用并重新打开 ClearPane。更新脚本先备份原插件。
